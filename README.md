# مشاريعي — Projects Dashboard

لوحة عربية تعرض حالة كل مشاريعك في مكان واحد، بكلام بسيط يفهمه أي شخص ما يعرف برمجة:
هل الموقع شغال؟ متى آخر تحديث؟ متى آخر فحص أمان؟ ووش المطلوب منك؟

An Arabic (RTL) dashboard that shows the status of all your projects in one place, in plain language.
One static page, no build step, no server, no account.

## المزايا
- دوّارة بطاقات ثلاثية الأبعاد بألوان متحركة. الرقم الكبير = كم يوم مرّ على آخر فحص أمان.
- تضغط البطاقة فتطير جنب شرح بسيط: هل الموقع شغال، آخر تحديث، الأمان، وش الموضوع، وش المطلوب منك.
- فلتر حسب الحالة: يحتاج إجراء / يحتاج متابعة / سليم / ينتظر اعتمادك.
- شريط «أهم شي الحين» يعرض أول خطوة في أخطر مشروع.
- علامة «تم» لكل خطوة، وسجل زمني لكل مشروع.
- قائمة مهام مصنّفة بالأهمية (عالية / متوسطة / منخفضة)، تضم مهامك وخطوات المشاريع.
- زر «نفّذها» ينسخ طلبًا جاهزًا ويفتح Claude Code لتنفيذ الخطوة.
- خلفية شبكة تنحني حول المؤشر أو الإصبع.
- يحترم «تقليل الحركة» في الجهاز، ويشتغل على الجوال.

## التشغيل
افتح المجلد بأي خادم ملفات بسيط:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أول مرة تفتح الصفحة تحمّل بيانات تجريبية خيالية من `demo.json`.

## بياناتك
- **بياناتك تنحفظ في متصفحك فقط (localStorage).** ما ترسل لأي خادم، وما تنتقل لجهاز ثاني لحالها.
- من أسفل الصفحة: **«استيراد بياناتي (JSON)»** و**«تصدير»** و**«رجّع البيانات التجريبية»**.
- شكل الملف هو نفس شكل `demo.json`: قائمة `projects`، وكل مشروع فيه:

| الحقل | المعنى |
|---|---|
| `name`, `kind` | اسم المشروع ونوعه |
| `status` | واحدة من: `يحتاج إجراء`، `يحتاج متابعة`، `سليم`، `ينتظر اعتمادك` |
| `live`, `url` | هل له موقع شغال، ورابطه |
| `updDate` / `updDaysAgo` | آخر تحديث (تاريخ `YYYY-MM-DD` أو عدد الأيام الماضية) |
| `secDate` / `secDaysAgo` | آخر فحص أمان (`null` = ما فيه فحص) |
| `secWarn` | نزلت ميزة مهمة بعد آخر فحص |
| `na` | ما يحتاج فحص أمان (مثل ملفات التصميم) |
| `lead`, `what`, `siteTxt`, `updTxt`, `secTxt`, `issue` | الشرح البسيط |
| `steps` | الخطوات: نص، أو `{ "text": "...", "task": "طلب جاهز لـ Claude Code" }` |
| `repo` | المستودع (يظهر في طلب «نفّذها») |
| `history` | السجل: `{ "date" أو "daysAgo", "kind": "security|update|issue|fix", "text" }` |

كل النصوص تُعرض كنص عادي، فما يمكن لملف مستورد يشغّل كود في الصفحة.

## النشر على Netlify
المجلد جاهز كما هو: `netlify.toml` ينشر الجذر ويضيف ترويسات أمان.
اسحب المجلد إلى Netlify أو اربط المستودع.

## الحركة والأداء
- الحركة بمكتبة [Motion](https://motion.dev).
- الطبقات المتحركة على البطاقة الأمامية فقط، وتتوقف أثناء السحب.
- الشبكة ترسم الجزء القريب من المؤشر فقط، وتتوقف أول ما يسكن.

## داخل Claude
إذا فتحت نفس الصفحة كـ Artifact في Claude، تستخدم قاعدة بيانات Claude بدل المتصفح، فتتزامن بين أجهزتك.
وتقدر تطلب من Claude يحدّث البيانات لك كل أسبوع.
